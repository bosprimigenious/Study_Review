## 产品原则

- 第一屏必须让用户继续复习，不做营销页。
- 核心按钮围绕：上传资料、分析往年题、生成今晚计划、开始摸底、继续错题。
- 少做长总结，多做主动回忆。
- 计划必须结束于可执行动作。
- 任何“预测”都必须表达为基于本地往年题的高频模式，不暗示泄题。

## 近期产品重点

- 从课程页直接进入第一题。
- 试卷分析和今晚计划成为前端主流程。
- 错题复查成为回访理由。
- OCR 证据可被用户检查，而不是藏在后台。
