# 更新与迭代计划

最后更新：2026-06-27  
适用仓库：`study-review-skill`  
主目标：把已经跑通的本地复习闭环，迭代成可在真实期末周稳定使用的课程复习产品。

## 北极星

用户不需要理解仓库结构，也能在 2 分钟内从一门课程进入第一道有来源依据的练习题。

核心闭环保持不变：

```text
登记资料
  -> 分析重点
  -> 生成变式题
  -> 生成今晚计划
  -> 一题一答
  -> 记录错题
  -> 到期复查
```

## 版本路线

### v0.6：文档与真实课程收束

目标：让项目维护者能快速判断“现在做什么、怎么验收、文档去哪找”。

交付：

- `docs/` 文档体系建立完成。
- README 指向新的文档入口。
- 真实课程验收清单固定下来。
- OCR / PDF 工具进入文档索引，不再散落在根目录。
- 旧计划文档标注职责，避免多个 roadmap 互相抢主导权。

验收：

- 新维护者只读 `README.md` 和 `docs/README.md` 能找到所有关键文档。
- `docs/UPDATE_AND_ITERATION_PLAN.md` 是唯一当前迭代计划入口。
- `SKILL.md` 保持短契约，不吸收长规划。

### v0.7：真实课程端到端验证

目标：至少 3 门真实课程完成闭环，不再只依赖 fixture。

优先课程：

- `计算机网络`
- `概率论与数理统计`
- `计算机组成原理`

任务：

- 为每门课生成或刷新 `review/` 工作区。
- 跑通分析、出题、计划、答题、错题、due 查询。
- 对扫描件或图像型 PDF 使用 `scripts/ocr/` 产出可核验文本或页面图。
- 记录每门课的失败点和修复项。

验收：

- 每门课至少生成 5 道可追溯题。
- 每门课至少完成 1 次 90 分钟计划。
- 每门课至少记录 1 条错题，并能被 `due_today.py` 查回。
- 事实来源能追溯到本地文件名、页图、OCR 文本或用户输入。

### v0.8：前端主流程可用

目标：浏览器里完成主流程，终端只作为开发和排障工具。

任务：

- 课程列表能稳定读取真实课程目录。
- 课程页显示资料、分析状态、计划状态和错题状态。
- 试卷分析、生成题、生成计划按钮有明确 loading、empty、error 状态。
- Quiz 页面支持答题、判分、记录错题。
- 前端所有请求错误显示可行动信息。

验收：

- 从打开网页到第一题不超过 2 分钟。
- 没有 CLI 背景的用户能完成一次“分析 -> 计划 -> 答题”。
- 前端 build 通过，关键路径有最小交互测试或手工验收记录。

### v0.9：资料摄取与 OCR 流程产品化

目标：把“文件名推断 + 手工 OCR”升级成可重复的资料摄取流程。

任务：

- 给 PDF/PPT/图片资料建立统一 ingest 状态。
- 将 `scripts/ocr/*.swift` 的使用方式纳入 API 或明确的 CLI wrapper。
- 区分 native text、Vision OCR、渲染页图三种证据来源。
- 对公式密集页面标注“需人工核验”。
- 为 OCR 输出建立稳定目录约定。

验收：

- 扫描 PDF 能产出 OCR 文本和页图索引。
- 生成题不会把 OCR 结果当作未经核验的公式真值。
- OCR 失败时有可复现命令和错误记录。

### v1.0：期末周可用版

目标：面向真实使用，而不是只面向开发者演示。

完成标准：

- 3 门真实课程跑通。
- 前端能完成核心闭环。
- 每个用户可见结论都有本地来源。
- 错题复查可连续使用至少 7 天。
- 文档、测试、示例和 README 一致。

## 迭代节奏

每轮迭代按 4 步走：

1. **选一个用户闭环**：例如“概率论扫描卷 -> OCR -> 出题 -> 答题”。
2. **先补验收文档**：在 `docs/operations/` 或 `tests/*_results.md` 写清楚怎么判定完成。
3. **实现最小功能**：优先复用 CLI，API 和前端只包装稳定行为。
4. **更新索引**：功能落地后同步更新 README、`docs/README.md` 和相关分区索引。

## 不做清单

- 不先做通用笔记生成器。
- 不在没有真实课程验证前重构成复杂多 agent。
- 不让 LLM 直接写长期状态文件。
- 不把外部网页当作课程事实来源。
- 不为商业化提前牺牲本地离线闭环。

## 质量门槛

每个进入主线的功能必须回答：

- 用户能从哪里触发？
- 数据写到哪里？
- 失败时怎么恢复？
- 哪个测试或验收记录证明它能跑？
- 哪篇文档负责解释它？

没有这 5 个答案的功能，只能进入实验分支或 backlog。
