# Subject Profiles

## 毛概 / 政治理论

Best modes:

- Closed-Book Recitation
- Active Recall
- Sprint

Focus:

- chapter structure
- key concepts and named formulations
- historical background
- "为什么 / 怎么做 / 意义" answer frames
- compare-and-contrast questions

Good prompts:

- 简述 X 的主要内容。
- 为什么说 X？
- X 和 Y 有什么区别？
- 补全这段表述中的关键词。
- 给你一个关键词，说出它属于哪一章、解决什么问题。

## 概率论与数理统计

Best modes:

- Problem Solving
- Diagnostic
- Mistake Log

Focus:

- conditional probability and independence
- distributions and density functions
- functions of random variables
- two-dimensional random variables
- expectation, variance, covariance
- law of large numbers and central limit theorem
- sampling distributions
- parameter estimation
- hypothesis testing

Require formulas with conditions and clear support regions.

Common mistakes:

- confusing density and distribution functions
- missing support region
- treating uncorrelated as independent
- using CLT without checking approximation assumptions
- mixing estimator, estimate, and parameter
- wrong rejection region in hypothesis testing

## 计算机网络

Best modes:

- Active Recall
- Flow Explanation
- Sprint

Focus:

- layered architecture
- encapsulation and addressing
- Ethernet, ARP, IP, routing
- TCP vs UDP
- TCP handshake and teardown
- congestion control vs flow control
- DNS, HTTP, and application protocols
- delay, throughput, subnetting, CRC if present

Good prompts:

- 从浏览器输入 URL 到页面出现，发生了什么？
- ARP 和 DNS 分别解决什么映射？
- TCP 为什么需要三次握手？
- 拥塞控制和流量控制区别是什么？

## 计算机组成原理

Best modes:

- Problem Solving
- Concept Contrast
- Diagnostic

Focus:

- number representation
- fixed/floating point arithmetic
- ALU and datapath
- instruction format and addressing modes
- memory hierarchy and cache
- CPU control and pipeline if included

Require bit width, signedness, and step-by-step calculation.

Common mistakes:

- mixing original code, inverse code, and complement code
- ignoring word length
- confusing logical and arithmetic shifts
- cache tag/index/offset split errors
- CPI or speedup formula misuse

## 理论计算机基础

Best modes:

- Definition Recall
- Construction
- Proof Sketch

Focus:

- languages and grammars
- finite automata
- regular expressions
- context-free grammar and PDA if present
- Turing machines if present
- decidability and computability if present

Require precise definitions, construction steps, proof ideas, and counterexamples.
