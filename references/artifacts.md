# Study Artifacts

Create files only when useful for continued study or when the user asks.

Recommended folder layout:

```text
科目/
├── 原始课件...
└── review/
    ├── 考点提纲.md
    ├── 主动回忆题.md
    └── 复习记录.md
```


## Simple Spaced Repetition

Rating:

- `忘了`: review today and tomorrow
- `困难`: review in 1 day
- `还行`: review in 3 days
- `很熟`: review in 7 days

For exam crunch:

- `忘了`: later in the same session
- `困难`: next day
- `还行`: two days later
- `很熟`: before exam only
